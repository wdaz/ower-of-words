# Characters

KayKit Character Pack: Adventurers 1.0 by Kay Lousberg (https://kaylousberg.itch.io/kaykit-adventurers),
CC0 1.0 Universal (public domain, no attribution required; credited anyway, thank you Kay).
Source: https://github.com/KayKit-Game-Assets/KayKit-Character-Pack-Adventures-1.0

`Knight`, `Barbarian`, `Mage`, `Rogue`, `Rogue_Hooded` hold the meshes (256px atlas, no clips);
`anims.glb` holds the shared clips the game plays. Rebuilt with `tools/build-characters.mjs`.
